# 发布说明（维护者）

将 **文档转 Markdown** 源码与 exe 发布到 GitHub 的步骤。

## 前提

GitHub **不支持**用账号密码直接推送代码，需先登录一次：

```powershell
cd doc2md
.\tools\gh\bin\gh.exe auth login
```

按提示在浏览器完成授权（选择 HTTPS、登录 GitHub 账号即可）。

## 一键发布

```powershell
.\scripts\publish.ps1
```

脚本会自动：创建仓库 → 推送源码 → 打标签 `v1.7.2` → 上传两个 exe 到 Releases。
