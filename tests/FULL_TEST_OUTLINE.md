# 全格式转换测试大纲（审阅版）

> 依据 Microsoft MarkItDown 内置转换器 + 本工具当前能力整理。  
> **本阶段只列大纲与步骤，等你确认后再动手造样例与跑测。**

---

## 〇、总原则（每个格式都要过）

每条用例统一记录 4 类结果：

1. **能否转换**（成功 / 失败 / 缺依赖 / 需云服务）
2. **结构保留**（标题、列表、表格、链接、代码等）
3. **视觉样式**（颜色、字号、字体、高亮 —— 预期多数会丢，属正常）
4. **LLM 友好度**（关键事实能否被抽到；有无 CSS/乱码噪声）

### 通用负面用例（所有格式尽量覆盖）

| 编号 | 场景 | 目的 |
|------|------|------|
| G-01 | 空文件 / 几乎无内容 | 不崩溃，提示可读 |
| G-02 | 超大文件（可选，抽样） | 性能与内存 |
| G-03 | 文件名含中文、空格、特殊符号 | 路径兼容 |
| G-04 | 错误扩展名（内容与后缀不符） | 探测/报错是否合理 |
| G-05 | 损坏/截断文件 | 错误信息是否友好 |
| G-06 | 通过 GUI 选文件 + 保存 `.md` | 端到端 |

### 能力分层（测试时标注）

| 层级 | 含义 | 本机现状 |
|------|------|----------|
| **L1 本地内置** | 装好依赖即可测 | 优先全覆盖 |
| **L2 可选本地依赖** | 如 `speech_recognition`、`exiftool` | 能装则测，不能则标「跳过+原因」 |
| **L3 需 LLM Key** | 图片描述 / OCR 插件 | 有 Key 再测，否则标「待条件」 |
| **L4 需 Azure** | Document Intelligence / Content Understanding | 无账号则标「待条件」；**本地视频高质量转换属此类** |

## 二、分格式测试步骤（面面俱到）

### A1 Word（`.docx`）— 用户最常遇到

| 步骤 | 用例名 | 样例要包含 | 检查点 |
|------|--------|------------|--------|
| A1-01 | 标题层级 | Heading 1~3 | 输出 `#`/`##`/`###` |
| A1-02 | 段落与换行 | 多段、软回车 | 段落不粘连 |
| A1-03 | 字体样式 | 红/蓝字、大号/小号、中英字体 | **颜色字号应丢失**；文字仍在 |
| A1-04 | 强调 | 加粗、斜体、下划线、删除线 | 加粗/斜体多能留；下划线/删除线可能丢 |
| A1-05 | 高亮/底纹 | 黄底文字 | 预期丢失视觉，文字保留 |
| A1-06 | 列表 | 项目符号、编号、多级列表 | `*` / `1.` / 缩进层级 |
| A1-07 | 基础表格 | 表头+3 行数据 | Markdown 表可读 |
| A1-08 | 复杂表格 | 合并单元格、空单元格、多列表 | 记录合并是否拆平/错位 |
| A1-09 | 超链接 | 文内链接、外部 URL | `[text](url)` |
| A1-10 | 图片 | 内嵌图 + 题注 | 有无路径/占位/丢失说明 |
| A1-11 | 页眉页脚/页码 | 页眉公司名、页脚页码 | 是否进入正文或被忽略 |
| A1-12 | 脚注/尾注 | 正文引用 + 脚注 | 是否保留引用关系 |
| A1-13 | 文本框/形状文字 | 文本框内关键句 | 是否提取 |
| A1-14 | 目录域 | 自动目录 | 是否变成纯文本标题列表 |
| A1-15 | 中英混排+全角标点 | 真实办公文风 | 无乱码 |
| A1-16 | 批注/修订 | 若可生成 | 是否混入或忽略 |
| A1-17 | 多节/分栏 | 两栏排版 | 阅读顺序是否合理 |
| A1-18 | 老格式对照 | 另存失败用 `.doc` | 明确报错 |

## 三、建议执行顺序（确认后按此推进）

```
阶段 1  L1 办公核心：Word / Excel / PPT / PDF / HTML / CSV / JSON
阶段 2  L1 其余文档：EPUB / IPYNB / TXT / MD / XML / RSS / ZIP / MSG
阶段 3  L1/L2 URL：普通网页 / Wiki（YouTube 视依赖）
阶段 4  L2 媒体：音频；图片基线（无 LLM）
阶段 5  边界与失败：.doc / 加密 / 损坏 / 不支持扩展名
阶段 6  （可选）L3 LLM 图片；L4 Azure 视频/扫描件
阶段 7  GUI 端到端抽测 + 汇总报告（LLM 友好度）
```
