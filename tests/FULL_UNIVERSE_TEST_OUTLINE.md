---

## 〇、能力分层（每条用例要标注）

| 层级 | 含义 | 本工具当前 |
|------|------|------------|
| **L1** | 本地内置 / 已装依赖即可 | 优先全覆盖 |
| **L2** | 可选本地依赖（ffmpeg、exiftool、联网 STT 等） | 能装则测，否则 Skip+原因 |
| **L3** | 需 LLM API（图片描述 / OCR 插件） | 无 Key 则 Skip |
| **L4** | 需 Azure（Doc Intel / Content Understanding） | 无账号则 Skip |

### 通用检查维度（每个格式都要过）

1. **能否转换**（成功 / 失败 / Skip）  
2. **结构**：标题、列表、表格、链接、代码块  
3. **内容**：关键标记/数值是否保留  
4. **噪声**：NaN、Unnamed、无意义空列、过度转义  
5. **LLM 友好**：是否便于抽取事实  
6. **图/媒体**：有图是否可感知（嵌入 / 占位 / 仅图注）

### 通用负面用例（跨格式）

| ID | 场景 |
|----|------|
| G-01 | 空文件 |
| G-02 | 超大文件（抽样） |
| G-03 | 中文/空格/括号文件名 |
| G-04 | 扩展名与内容不符 |
| G-05 | 损坏/截断文件 |
| G-06 | 加密/密码文件（预期失败） |
| G-07 | GUI 选文件→预览→复制→保存 |
