# 文档转 Markdown — 使用说明

**版本：v1.7.11**

---

## 一、下载与安装

### 下载地址

👉 **https://github.com/appuser-beep/doc2md/releases/latest**

| 文件 | 说明 |
|------|------|
| **文档转Markdown.exe** | 图形界面，适合日常手动转换 |
| **doc2md-cli.exe** | 命令行，适合批量、脚本、管道 |

两个 exe **转换能力相同**，按使用习惯选一个即可。无需安装 Python。

### 安装步骤

1. 打开上方链接，在 **Assets（附件）** 中下载 exe。
2. 将 exe 放到任意文件夹（路径建议只用英文和数字）。
3. 双击 **文档转Markdown.exe** 启动。

> **说明：** 首次启动可能需等待十几秒（内置环境解压）。Windows 若提示「未知发布者」，选择「仍要运行」即可。

---

## 二、图形界面用法

1. **选择文件** — 支持 PDF、Word、Excel、PPT、图片、ZIP 等（详见软件内「格式说明」）。
2. **或输入 URL** — 支持普通网页、Wikipedia、Bing、YouTube 等。
3. 点击 **开始转换**，右侧预览 Markdown。
4. 点击 **另存为…** 保存 `.md` 文件。

### 设置菜单

| 菜单 | 用途 |
|------|------|
| 格式说明 | 查看完整支持格式与限制 |
| 大模型设置 | 图片描述、内嵌图 OCR（需 API Key） |
| Azure 设置 | 扫描 PDF、视频、EML 等（需 Azure 账号） |
| 高级设置 | 样式映射、ExifTool、窄接口、保留内嵌图、自定义插件 |

设置保存在：`C:\Users\你的用户名\.doc2md\`

## 三、命令行用法（doc2md-cli.exe）

与图形版共用引擎与配置。

```powershell
# 单文件
doc2md-cli.exe 报告.pdf -o 报告.md

# 从管道读取
type 报告.pdf | doc2md-cli.exe -x pdf -o 报告.md

# 窄接口（不使用 Excel / Notebook / ZIP 增强）
doc2md-cli.exe --local-only 文档.docx -o 文档.md

# 保留 PPT 内嵌 base64 图片
doc2md-cli.exe --keep-data-uris 幻灯片.pptx -o 幻灯片.md

# 查看已安装插件
doc2md-cli.exe --list-plugins
```

## 四、从源码运行（开发者）

### 源码地址

👉 **https://github.com/appuser-beep/doc2md**

### 环境要求

- Windows 10 / 11
- Python 3.10 或以上

### 步骤

```powershell
git clone https://github.com/appuser-beep/doc2md.git
cd doc2md
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt

# 启动图形界面
.\.venv\Scripts\python.exe main.py

# 或命令行
.\.venv\Scripts\python.exe cli.py 样例.pdf -o 样例.md
```

### 自行打包 exe

```powershell
.\build.ps1
```

生成文件位于 `dist\` 目录。

## 五、常见问题

**Q：转换后颜色、字号没了？**  
A：Markdown 保留结构与语义，不保留视觉样式；标题、列表、表格、链接会保留。

**Q：大模型设置里随便填模型名可以吗？**  
A：不可以。需要 OpenAI 兼容接口，且模型须支持识图（如 gpt-4o）。纯文本模型通常无法描述图片；名称须与服务商控制台一致。Azure 设置是另一套微软云账号，与大模型密钥无关。

**Q：扫描件 PDF 几乎没文字？**  
A：请在「大模型设置」或「Azure 设置」中启用 OCR / 文档智能服务。

**Q：ZIP 提示实际是 RAR？**  
A：文件扩展名是 .zip 但内容可能是 RAR/7z，请用 7-Zip 重新压缩为 ZIP。

**Q：图形版和命令行版有什么区别？**  
A：转换能力相同；图形版便于手动操作，命令行版便于批量与自动化。
